## 요약

현재 Bulldozer M 공고는 후보자의 핵심 Unity/C# 경험과 리드 경험에 맞지만, 공고 경력 기준 5년 이상과 후보자의 Unity 실무 3년(현재 4년차) 사이에 명확한 간격이 있다. 지원은 포기할 이유가 없지만 서류 자동 필터 가능성이 있어 이 한 공고에만 기대지 않는다.

실행 전략은 **마감 전에 Bulldozer M에 사실대로 지원하고, 동시에 3~4년대 Unity 클라이언트 공고를 Supercent에서 계속 찾는 것**이다. 하이브리드 퍼즐 클라이언트 개발자(3~7년) 공고가 검색되었으나 검색 스냅샷이 오래되어 현재 접수 중인지는 확인되지 않았다.

## 지원서에서 바꿀 점

1. 슈퍼센트 지원 동기에는 프로젝트 다양성, 초기 커리어에서의 도전, 한 프로젝트에 깊이 기여하고 장기적으로 성장하고 싶은 동기를 담는다.
2. 연봉은 사용자의 중요한 기준이지만 자기소개서 문장에 직접 넣지 않는다. 지원 양식의 희망 연봉란이나 최종 처우협의에서 사용자 목표에 맞춰 다룬다.
3. 하울리도그의 개발 기간은 2026.06–09, 출시 월은 2026.09로 표시한다.
4. 성과 수치가 없으면 “출시 완료”로 표현하고 다운로드/매출/리텐션 성과를 만들어내지 않는다.
5. 이력서에는 실무 Unity 3년, 현재 4년차를 정확히 쓴다. 공식 재직/계약일과 실무 참여일(2023.05)은 증빙에 맞춰 별도로 적는다.
6. 공고 전형에 과제와 오프라인 테스트가 포함될 수 있으므로 코드 설명, 자료구조, 구현 디버깅을 사례 중심으로 준비한다.

- 계정/세이브/서버 상태와 오류 복구 방식
- Codex Agent 코드 검토 요청 후 직접 플레이·수정 요청을 반복했고, 해소되지 않는 병목은 직접 찾아 수정함. 병목 사례, 클라이언트/서버 코드 대조 방식, 자동 빌드·배포 구성의 구체 절차를 설명할 자료
- CatchU 텍스처 메모리 문제의 재현 조건, 기기, Profiler에서 본 현상, 수정 뒤 확인 방법
- CatchU 상용 프로젝트의 실제 클라이언트팀 규모와 본인 역할 경계
- 패턴/아키텍처(MVC, MVVM, ECS 등)를 실제로 적용했거나 적용하지 않았다면 선택 이유
- 성능, 메모리, 프레임/로딩 관련 Howly Dog 디바이스 측정 결과가 있는지

## 종합 판단

지원 적합성은 **기술·리더십 기준 중상, 경력 연차 기준 낮음**이다. 가장 강한 차별점은 출시 가능한 개인 게임을 끝까지 만든 경험과 실제 운영 문제의 Profiler 기반 해결을 함께 제시할 수 있다는 점이다. 가장 큰 위험은 채용 경력 필터, AI 결과물 검수의 구체 사례와 기술 테스트에서의 독립 구현 능력 증명 필요, 게임 성능 최적화 증거가 상거래 앱에서 나온 점이다. 이력서와 자기소개서만 길게 늘리기보다 위 증거를 확보하고, 포지션 적합도가 더 높은 3~7년 Unity 게임 클라이언트 채용을 병행 추적한다.
