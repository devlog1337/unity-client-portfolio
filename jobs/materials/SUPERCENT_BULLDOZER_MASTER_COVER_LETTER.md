# 자기소개서 | Bulldozer Master 클라이언트 개발자(계약직)

저는 Unity 모바일 클라이언트의 실서비스 운영과 AI 도구를 활용한 개인 게임 출시를 함께 경험한 개발자입니다. 비투비커넥트 소속으로 KLP CatchU의 클라이언트 개발 및 운영을 맡아 UI, API 연동, 런타임 리소스, 사용자 이슈를 다뤘습니다. 클라이언트 파트장 역할로 코드 리뷰와 온보딩, 팀 개발 규칙 정리도 수행했습니다.

개인 프로젝트 Howly Dog는 2026년 6월부터 9월까지 진행해 제 Apple 개발자 계정으로 App Store에 출시했습니다. 게임 구조와 기능 흐름은 직접 설계했고, 냥코대전쟁과 캔디팡을 참고해 퍼즐의 방향을 정했습니다. Copilot으로 시작해 Codex Agent 중심으로 구현·업데이트를 진행했으며, 생성된 코드를 검토 요청하고 직접 플레이해 문제를 찾은 뒤 수정 요청을 반복했습니다. UI/UX와 프리팹 배치는 직접 수정했고, 반복 해결되지 않는 병목은 직접 찾아 고쳤습니다.

이 과정에서 AI가 코드를 생성하는 것만으로 품질이 보장되지 않는다는 점을 배웠습니다. 버튼 배치 수정이 코드로 잘못 진행되자 프리팹 수정 규칙을 Harness에 추가했고, NetworkManager의 로딩 처리를 요청마다 일관되게 적용하도록 기준을 정리했습니다. 두 PC 환경에서 누락되거나 잘못된 커밋으로 작업이 꼬였을 때는 커밋·기기 간 작업 규칙을 보완했습니다. 프로젝트 규칙을 지속적으로 갱신한 뒤 버그 수정 요청 누락은 거의 없어졌습니다.

개발은 Mini PC의 Unity CLI를 중심으로 진행하고, iOS 빌드는 Mini PC에서, Xcode를 통한 실제 앱 배포는 MacBook에서 수행합니다. Codex에 App Store 목업 이미지 등록과 설명 수정을 요청하고, 인증 입력은 직접 처리합니다. 이를 통해 설계, 작업 분해, 코드 검토, 직접 플레이, 스토어 운영까지 이어지는 개인 프로젝트 개발 흐름을 만들었습니다.

Bulldozer Master 클라이언트 개발 업무에서도 게임 시스템과 플레이 흐름을 빠르게 이해하고, 플레이어 경험과 유지보수성을 함께 고려해 기여하겠습니다. AI 활용 자체를 성과로 내세우기보다, 요구사항과 품질 기준을 명확히 하고 결과물을 직접 검증하는 개발자로 일하겠습니다.
